# 🥗 Calorimeter App

Calorimeter is an Android application designed to help users monitor their daily nutrition and calorie intake. The app integrates with the USDA FoodData Central API to provide accurate nutritional information while securely storing user data using Firebase.

## ✨ Features

- User authentication
- Search food items
- Daily calorie tracking
- Nutrition analysis
- Food history
- Firebase integration

## 🛠 Tech Stack

- Kotlin
- Android Studio
- Firebase Authentication
- Firestore Database
- USDA FoodData Central API
- Material Design

## 🚀 Installation

Clone the repository and open it in Android Studio.

```bash
git clone https://github.com/NandanSharma94439/calorimeter-app.git
```

Sync Gradle and run the application on an Android device or emulator.
